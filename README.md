# Your Digital Library

Your Digital Library is a responsive, interactive book discovery website that helps readers explore books from different categories. Powered by the **Open Library API**, it allows users to search for books, view book covers and details, and save their favorite books for later.

## Features

- **Book Discovery:** Explore books retrieved from the Open Library API.
- **Book Covers:** View available book cover images.
- **Search Functionality:** Search for books by title or author.
- **Category Filtering:** Browse books using category filters.
- **Book Details:** Explore available information about books.
- **Favorites:** Add and remove favorite books.
- **Persistent Favorites:** Favorite books remain saved after refreshing the page using browser `localStorage`.
- **Responsive Design:** Adapts to mobile, tablet, and desktop screens.
- **Accessible Controls:** Use clear search and category controls to navigate the collection.

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and npm installed on your computer.

### Installation

Clone the repository:

```bash
git clone https://github.com/Keniaumwali/your-digital-library.git
```

Navigate to the project folder:

```bash
cd your-digital-library
```

Install the dependencies:

```bash
npm install
```

### Run the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.

## Production Build

To create an optimized production build, run:

```bash
npm run build
```

To preview the production build locally, run:

```bash
npm run preview
```

The generated production files are placed in the `dist` directory.

## API Sources

This project uses the Open Library APIs to retrieve book information and cover images.

- [Open Library Search API](https://openlibrary.org/dev/docs/api/search)
- [Open Library Covers API](https://openlibrary.org/dev/docs/api/covers)

Book availability, descriptions, and cover images depend on the information provided by Open Library.
