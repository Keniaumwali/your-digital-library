# Your Digital Library

Your Digital Library is a responsive book discovery website that helps readers explore books, search by title or author, and browse different categories.

## Features

- Responsive layout for mobile, tablet, and desktop screens
- Book collection with titles, authors, categories, and descriptions
- Search books by title or author
- Filter books by category
- Accessible search form and category controls
- Clean design built with Tailwind CSS

## Technologies

- HTML
- Tailwind CSS
- JavaScript
- Vite

## Getting Started

### Requirements

Install Node.js and npm.

### Installation

Clone the repository and enter the project folder:

    git clone https://github.com/Keniaumwali/your-digital-library.git
    cd your-digital-library
    npm install

### Run the project

    npm run dev

Open the local URL displayed in your terminal.

## Production Build

To check the production build, run:

    npm run build

## Project Purpose

This project demonstrates responsive frontend development, JavaScript DOM manipulation, search, category filtering, and project setup with Vite and Tailwind CSS.
